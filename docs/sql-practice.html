怎么练

在本机启动图鉴（start-atlas.cmd），打开 http://127.0.0.1:8790 的「SQL 控制台」， 把这 15 条 SQL 粘进去跑；也可以直接 sqlite3 data/atlas.sqlite。 每题都给了参考答案与考点，建议先自己写再看。

表结构见 DATASETS.md；数据表清单：poetry_tang / poetry_ci / poetry_authors / words / words_senses / words_examples / words_collocations / ex_exercises / geo_countries / geo_states / geo_cities / well_datasets。

题目（点开看答案）

Q01唐诗样本里一共有多少首诗？

考点：COUNT(*)

SELECT COUNT(*) AS 诗数 FROM poetry_tang;
Q02宋词里作品最多的 5 位作者是谁？各多少首？

考点：GROUP BY + ORDER BY + LIMIT

SELECT author, COUNT(*) AS n FROM poetry_ci GROUP BY author ORDER BY n DESC LIMIT 5;
Q03唐诗里标题带「月」的诗，取前 8 首

考点：LIKE 模糊匹配

SELECT author, title FROM poetry_tang WHERE title LIKE '%月%' LIMIT 8;
Q04宋词平均每首多少字？（保留 1 位小数）

考点：聚合函数 AVG/MIN/MAX + ROUND

SELECT ROUND(AVG(char_count), 1) AS 平均字数, MIN(char_count) AS 最短, MAX(char_count) AS 最长 FROM poetry_ci;
Q05出现超过 300 次的词牌有哪些？

考点：HAVING 过滤分组

SELECT rhythmic, COUNT(*) AS n FROM poetry_ci GROUP BY rhythmic HAVING COUNT(*) > 300 ORDER BY n DESC;
Q06唐诗里最长的一首诗是哪首？多少字？

考点：排序取 Top1

SELECT title, author, char_count FROM poetry_tang ORDER BY char_count DESC LIMIT 1;
Q07雅思词库里 B2 及以上的词有多少个？

考点：IN + GROUP BY

SELECT cefr, COUNT(*) AS n FROM words WHERE cefr IN ('B2','C1','C2') GROUP BY cefr ORDER BY cefr;
Q08词条 library 的所有释义（按顺序）

考点：按主键/索引列筛选

SELECT idx, pos, zh FROM words_senses WHERE word_id = 'library' ORDER BY idx;
Q09三表 JOIN：拿 library 的第一条释义和第一条例句

考点：多表 JOIN + 复合条件

SELECT w.word, s.zh AS 释义, e.en AS 例句 FROM words w JOIN words_senses s ON s.word_id = w.word_id AND s.idx = 0 JOIN words_examples e ON e.word_id = w.word_id AND e.idx = 0 WHERE w.word = 'library';
Q10每个 CEFR 等级的词数占比（%）

考点：子查询做分母

SELECT cefr, COUNT(*) AS n, ROUND(100.0 * COUNT(*) / (SELECT COUNT(*) FROM words), 1) AS pct FROM words GROUP BY cefr ORDER BY cefr;
Q11带 public 的固定搭配有哪些？

考点：子表 LIKE

SELECT word_id, collocation, zh FROM words_collocations WHERE collocation LIKE '%public%' LIMIT 10;
Q12按身体部位统计动作数，只看超过 100 个的部位

考点：HAVING + 阈值

SELECT body_part, COUNT(*) AS n FROM ex_exercises GROUP BY body_part HAVING COUNT(*) >= 100 ORDER BY n DESC;
Q13不需要器材、目标肌群是腹肌的动作有哪些？

考点：多条件 AND

SELECT name, category, target FROM ex_exercises WHERE equipment = 'body weight' AND target LIKE '%abs%' LIMIT 10;
Q14人口最多的 10 个国家，并算每平方公里多少人

考点：算术表达式 + 别名

SELECT name, population, area_sq_km, ROUND(population / area_sq_km, 1) AS 人口密度 FROM geo_countries WHERE area_sq_km > 0 ORDER BY population DESC LIMIT 10;
Q15中国一共有多少座城市入库？

考点：按国家名统计

SELECT COUNT(*) AS 城市数 FROM geo_cities WHERE country_name = 'China';
