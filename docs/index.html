③ 三条能直接抄的 SQL

这些查询在本地 SQL 控制台里都能跑（15 道带答案的练习见 SQL 练习）。

-- 宋词里谁写得最多
SELECT author, COUNT(*) c FROM poetry_ci GROUP BY author ORDER BY c DESC LIMIT 5;

-- 一个词的释义 + 例句（三表 JOIN）
SELECT w.word, s.zh, e.en
FROM words w
JOIN words_senses s   ON s.word_id = w.word_id AND s.idx = 0
JOIN words_examples e ON e.word_id = w.word_id AND e.idx = 0
WHERE w.word = 'library';

-- 人口最多的 10 个国家
SELECT name, population FROM geo_countries ORDER BY population DESC LIMIT 10;

④ 本地跑起来

站点是静态的；真正的数据库和图鉴应用在仓库里，三个命令即可。

python scripts/fetch_data.py   # 拉数据（约 51MB，断点续传 + sha256 校验）
python scripts/build_db.py     # 建库（data/atlas.sqlite，12 张表）
python scripts/serve.py        # 起服务 → http://127.0.0.1:8790

Windows 下双击 start-atlas.cmd / stop-atlas.cmd 即可。 只读边界：数据库以 mode=ro 打开，只允许 SELECT/WITH/EXPLAIN，结果上限 500 行。
