可校验性

data/manifest.json 记录了每个文件的来源路径、git blob sha、字节数与 SHA-256，验收脚本会逐个比对。

# 校验全部下载文件
python scripts/verify.py

# 单独校验某个文件（Windows）
certutil -hashfile "data\raw\poetry\宋词\ci.song.0.json" SHA256
